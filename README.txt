PRÁCTICA WEB: LA ALBERCA
===========================

ARCHIVO PRINCIPAL
- index.html

PUBLICACIÓN CON GITHUB + NETLIFY
1. Crea un repositorio nuevo en GitHub, por ejemplo: practica-la-alberca.
2. En el repositorio, pulsa "Add file" > "Upload files".
3. Arrastra el archivo index.html y confirma el commit.
4. En Netlify, crea un proyecto mediante "Add new project" > "Import an existing project".
5. Elige GitHub, autoriza el acceso y selecciona el repositorio.
6. Como este proyecto es HTML puro:
   - Build command: dejar vacío
   - Publish directory: dejar vacío o usar "."
7. Pulsa "Publish" o "Deploy".
8. Copia la URL pública asignada por Netlify y entrégala.

EDICIÓN RÁPIDA
- Puedes sustituir "A. P." por tu nombre completo.
- Puedes cambiar el texto directamente desde GitHub con el icono del lápiz.
- Cada commit nuevo se publicará automáticamente si el repositorio está vinculado con Netlify.
